# STADS Field Evaluation Supplementary Materials

This repository contains the Online Resources accompanying the manuscript:

**A Composite Field-Evaluation Framework for Mapped Outputs from Digital Agriculture Tools: Combining Blind and System-Guided High-Precision Scouting**

The materials support the field evaluation of outputs from the Spatiotemporal Anomaly Detection System (STADS) and include de-identified scouting data, reviewer materials, record-linkage and reconciliation documentation, statistical-analysis code, and representative field examples.

## Repository contents

| Online Resource | Directory | Contents |
|---|---|---|
| **S1** | `S1_DeIdentified_ScoutingObservations` | De-identified blind paired-point scouting observations |
| **S2** | `S2_DeIdentified_Survey123FormAndObservations` | RTK-GNSS Survey123 data-collection form and de-identified scouting observations |
| **S3** | `S3_BlindRecordAudit` | Blind-record reconstruction and linkage rules, linkage audit, detailed secondary statistical methods, and sensitivity-analysis results |
| **S4** | `S4_BlankReviewerEvaluationWorkbook` | Blank reviewer-evaluation workbook |
| **S5** | `S5_ReviewerClassificationRubric` | Reviewer classification rubric |
| **S6** | `S6_DeIdentified_ReviewerEvaluationsAndScripts` | De-identified completed reviewer workbooks and associated Python processing and statistical-analysis scripts |
| **S7** | `S7_RTKScoutingExamples` | Representative de-identified field examples from RTK-GNSS-guided scouting |
| **S8** | `S8_RTKRecordAudit` | De-identified RTK-GNSS record-reconciliation and correction-audit materials |

`CITATION.cff` provides citation metadata for the repository.

## Data availability and reproducibility

Public materials have been de-identified. Precise coordinates, anomaly geometries, confidential farm and field identifiers, personally identifiable scout information, and proprietary STADS attributes and anomaly-generation methods are not included.

The reported statistical field evaluation can be reproduced from the shared materials. The original STADS anomaly-generation process and complete spatial reconstruction cannot be reproduced from this repository because proprietary methods and confidential spatial information are excluded.
